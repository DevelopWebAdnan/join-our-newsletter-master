### What I learned

<!-- Use this section to recap over some of your major learnings while working through this project. Writing these out and providing code samples of areas you want to highlight is a great way to reinforce your own knowledge. -->
While working through this project, I have learnt that the type attribute (type="email" or type="submit") for input elements of a form can be useful when we want to style each of the input elements of the form separately.
I have also learnt that a google font (for example: Poppins) may seem to be of a language other than English, but if we test it in our website, then we will see that the language of the font is actually English. So, instead of getting worried, just use the google font in your site and see the output.
